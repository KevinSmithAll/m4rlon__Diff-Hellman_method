# Алгоритм Диффи-Хеллмана на Python
Данный проект демонстрирует реализацию алгоритма Диффи-Хеллмана для обмена ключами с использованием языка программирования Python. 

## Алгоритм Диффи-Хеллмана 
Это метод безопасного обмена криптографическими ключами по незащищенному каналу. Он позволяет двум сторонам установить общий секретный ключ, который может быть использован для симметричного шифрования, даже если связь осуществляется по открытой сети.

## Что такое алгоритм Диффи-Хеллмана?
Алгоритм Диффи-Хеллмана включает несколько этапов для обеспечения безопасного обмена ключами между двумя участниками, Алисой и Бобом:

1) Выбор параметров: Обе стороны договариваются о двух параметрах: большом простом числе p и первообразном корне по модулю p, обозначаемом как g. Эти параметры открыты для всех участников общения.
2) Генерация закрытых ключей: Каждый участник генерирует свой закрытый ключ, выбирая случайное целое число. Например, Алиса выбирает a, а Боб выбирает b.
3) Расчет открытых ключей: Используя свои закрытые ключи и согласованные параметры, каждый участник вычисляет свой открытый ключ. Алиса рассчитывает свой открытый ключ, а Боб — свой.
4) Обмен открытыми ключами: Участники обмениваются своими открытыми ключами друг с другом.
5) Вычисление общего секретного ключа: Каждый участник использует открытый ключ другого участника и свой закрытый ключ для вычисления общего секретного ключа. Оба участника приходят к одному и тому же значению, создавая общий секретный ключ K.
6) Симметричное шифрование: Этот общий секретный ключ K может быть использован для шифрования последующих сообщений между Алисой и Бобом.
## Почему используется алгоритм Диффи-Хеллмана?
Алгоритм Диффи-Хеллмана обладает несколькими преимуществами:

Безопасность: Даже если злоумышленник перехватит переданные сообщения, ему будет практически невозможно извлечь общий секретный ключ, не зная закрытого ключа одного из участников.
Масштабируемость: Алгоритм легко адаптируется для поддержки множества участников.
Эффективность: Выполняемые вычислительные операции достаточно просты и эффективны, что делает алгоритм пригодным для различных приложений.

Алгоритм Диффи-Хеллмана сохраняет свою значимость и сегодня благодаря роли, которую он играет в обеспечении безопасности современных коммуникационных систем:

Интернет-безопасность: Протоколы, такие как TLS/SSL, используют алгоритм Диффи-Хеллмана для согласования сеансовых ключей при безопасной навигации в Интернете.
Виртуальные частные сети (VPN): Сервисы VPN полагаются на алгоритм Диффи-Хеллмана для установки защищённых соединений между пользователями и серверами.
Криптографические системы: Квантовоустойчивая криптография, такая как методы, основанные на суперсингулярных изогениях, часто заменяют или усиливают традиционные реализации алгоритма Диффи-Хеллмана.
Мобильные устройства: Многие мобильные приложения и устройства используют алгоритм Диффи-Хеллмана для защиты данных пользователей.
